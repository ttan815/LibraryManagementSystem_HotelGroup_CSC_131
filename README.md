** Note: You'll need to have two separate terminals open, one for the frontend and one for the backend.
To run the front end:

Go and open the front end folder in terminal, then do "npm install", that should load up all the data. Then you can load the website with "npm run dev".

To run the back end:

You will need to have Python 3.11 running:

Go and open the backend folder in terminal, then do "python3.11 -m venv venv ", which will create a virutal environment to download requirements from requirements.txt. Activate the virutal environment, (Ex: on Mac: source "source venv/bin/activate"). Then you can install the requirements with the command: "pip install -r requirements.txt".
